A single-line office joke for the make.fun bounty **"One-Line Office Jokes"**.

## The entry

> The water cooler bottle has been empty since Tuesday and everyone just walks past it — it's the longest-running team project in this office.

140 characters, one line. The joke is grounded in a real office detail — the empty water cooler bottle nobody ever replaces — and the laugh lands on the last words: the bottle outlasts every actual project.

## How to run

```bash
python3 main.py
```

This writes the entry to `/output/entry.txt`, then reads it back and verifies it is byte-identical to the entry, 1–199 characters, a single line, not whitespace-only, and with no trailing newline.
